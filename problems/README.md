# Practice problems

Every coding problem I solve, logged. Solutions live in the week folder they belong to; this file is
the index and, more usefully, the record of **how much help I needed**.

The hint count is the point. A problem solved with three hints is not solved. Patterns where the
hint count stays high are the ones to drill.

**Hint levels:** 1 restate the problem · 2 name the technique · 3 the algorithm in words ·
4 pseudocode · 5 full solution.

## Why this file exists

From Week 17 the course runs two problems a week for forty-two weeks, alongside everything else.
That is deliberate: Python ends at Week 16 and the interview sprint is Week 54, and coding fluency
decays faster than almost anything else. Without a standing habit, Week 54 becomes a rescue instead
of a sharpening.

Logging it is what makes the habit visible when it slips.
